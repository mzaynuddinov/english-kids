# Англисиро Омӯз

**Англисиро Омӯз** — барномаи офлайнӣ барои кӯдакони тоҷик. Кӯдак алифбо, калимаҳо, грамматикаи асосӣ, талаффуз, навиштан, санҷишҳои зирак, ёдрас ва пешрафтро дар як ҷо меомӯзад.

Версия: **2.4.4+29**

Номи барнома дар телефон ҳамеша **Англисиро Омӯз** аст.


## Мақсад

Кӯдак бояд ҳар дафъа фаҳмад: «Ҳозир чӣ кор кунам?» — гӯш кунад, нависад, интихоб кунад ё такрор кунад. Барнома барои кӯдакон содда, калон-тугма ва дӯстона аст.


## Имкониятҳо

### Алифбо
- Ҳарфҳои A–Z бо шакли хурд (a) ва swipe
- Ҳар ҳарф ҳолати алоҳидаи «Омӯхта шуд» дорад ва бозгашт карда мешавад
- Ҳарфҳо барои ҳар талаба алоҳида сабт мешаванд
- 🎉 Алифбо пурра омӯхта шуд! — 26 / 26
- Овози ҳарф ва овози калима ҷудо: **🔊 Ҳарф** / **🔊 Калима**

### Санҷиши Алифбо
- Ҳарфҳо омехта, на ҳамеша A → Z
- Рӯйхати саволҳо як маротиба сохта ва захира мешавад
- Пас аз «Ҷавоб» ҷавоб дигар иваз намешавад
- Натиҷаи ниҳоӣ бо ✓ / ✗ ва тугмаи **Аз нав санҷидан**

### Калимаҳо
- **500** калимаи бетакрор дар 10 ҳафта, офлайн (`data/vocabulary.json`)
- Ҳафтаҳо, рақамҳо, рангҳо, калимаҳои ибтидоӣ ва грамматика бе қулфи мавзӯъҳои пешин кушода мешаванд
- Тугмаи «Идома» танҳо роҳи пешниҳодшударо нишон медиҳад ва маҷбур намекунад
- Корти фишурда: мавзӯъ, IPA, ҷумлаи мисол, синоним/антоним (чип), сохти калима
- Амалҳо: 🔊 Гӯш кардан, 🔊 Ҷумла, 🔖 Барои баъд, ✓ Омӯхта шуд, ⏰ Ёдрас
- «Омӯхтам» дар ҳама ҷо ҳамон лаҳза нав мешавад
- Ҷустуҷӯи умумӣ (пеш аз Танзимот): англисӣ / тоҷикӣ / талаффуз; калимаи ноомӯхта бо 🔒 мемонад

### Грамматикаи асосӣ
- 10 дарс: I am, You are, He is, She is, It is, This is, These are, I have, I like, ҳозираи содда
- Дарсҳо аз аввал кушодаанд
- Шарҳи тоҷикӣ, мисолҳо, овоз ва машқи хурд

### Санҷиши калимаҳо
- Танҳо калимаҳои омӯхта
- То 25 савол, калимаҳои хато бештар такрор мешаванд
- Агар камтар аз 25 калима омӯхта бошад, санҷиш аз онҳо сохта мешавад

### Пешрафт ва волидон
- **Талабагон**: номҳо танҳо дастӣ илова мешаванд ва пас аз пӯшидани барнома ё гузашти вақт нест намешаванд. PIN низ як маротиба захира мешавад
- **Оғози омӯзиш**: алифбо, рақамҳо, рӯзҳои ҳафта, рангҳо, калимаҳои ибтидоӣ, ҳар ҳафта ва тамоми 500 калима
- **Пурсиши дастӣ**: «Дуруст ҷавоб дод», «Нодуруст ҷавоб дод», «Надонист», «Барои баъд», «Омӯхта шуд». Натиҷаи имрӯз ҳолати омӯзишро нест намекунад
- **Сертификат**: танҳо вақте ки ҳамин талаба ҳар 500 калимаи луғатро омӯхтааст. Нишон: «✓ 500 калима / 500 Words»
- Рӯзҳои ҳафта 7 ном доранд. Моҳҳои сол мавзӯи алоҳида нестанд, чунки дар луғат омода нестанд
- Калимаҳои омӯхта / захира / душвор
- **Калимаҳое, ки боз такрор кардан лозим аст**
- **Таърихи санҷишҳо** бо ҷузъиёти хондашаванда
- **Тақвими омӯзиш** — рӯзҳои ҳафта бо ✓ / ·
- **Омори омӯзиш** — имрӯз, ҳафта, дақиқӣ, пайдарпай

### Едраскуниҳо
- Саҳифаи **Ёдраскуниҳо**: давом / таваққуф / нест
- Ҳангоми оташ: TTS калимаро мехонад; агар TTS дар пасзамина кор накунад, огоҳӣ мемонад
