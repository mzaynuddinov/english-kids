# Англисиро Омӯз

**Англисиро Омӯз** — барномаи офлайнӣ барои кӯдакони тоҷик. Кӯдак алифбо, калимаҳо, грамматикаи асосӣ, талаффуз, навиштан, санҷишҳои зирак, ёдрас ва пешрафтро дар як ҷо меомӯзад.

Версия: **2.1.1+22**

Номи барнома дар телефон ҳамеша **Англисиро Омӯз** аст.


## Мақсад

Кӯдак бояд ҳар дафъа фаҳмад: «Ҳозир чӣ кор кунам?» — гӯш кунад, нависад, интихоб кунад ё такрор кунад. Барнома барои кӯдакон содда, калон-тугма ва дӯстона аст.


## Имкониятҳо

### Алифбо
- Ҳарфҳои A–Z бо swipe ва тирчаҳои ← →
- Ҳарфи ҷорӣ ҳангоми бозгашт нигоҳ дошта мешавад
- Ҳар ҳарф ҳолати алоҳидаи «Омӯхтам» дорад
- 🎉 Алифбо пурра омӯхта шуд! — 26 / 26
- Овози ҳарф ва овози калима ҷудо: **🔊 Ҳарф** / **🔊 Калима**

### Санҷиши Алифбо
- Ҳарфҳо омехта, на ҳамеша A → Z
- Рӯйхати саволҳо як маротиба сохта ва захира мешавад
- Пас аз «Ҷавоб» ҷавоб дигар иваз намешавад
- Натиҷаи ниҳоӣ бо ✓ / ✗ ва тугмаи **Аз нав санҷидан**

### Калимаҳо
- **500** калимаи бетакрор дар 10 ҳафта ва рӯзҳо, офлайн (`data/vocabulary.json`)
- Ҳар калима ҷумлаи табиӣ бо тарҷумаи тоҷикӣ дорад
- Ҳафтаҳо пай дар пай қулф: аввал алифбо, баъд Ҳафтаи 1, баъд Ҳафтаи 2…
- Корти фишурда: мавзӯъ, ҷумлаи мисол, 🔖, калима / талаффуз / тарҷума
- Амалҳо: 🔊 Гӯш кардан, 🔊 Ҷумла, 🔖 Барои баъд, ✓ Омӯхтам, ⏰ Ёдрас
- «Омӯхтам» дар ҳама ҷо ҳамон лаҳза нав мешавад

### Грамматикаи асосӣ
- 10 дарс: I am, You are, He is, She is, It is, This is, These are, I have, I like, ҳозираи содда
- Пас аз алифбо ва Ҳафтаи 5 кушода мешавад
- Шарҳи тоҷикӣ, мисолҳо, овоз ва машқи хурд

### Санҷиши калимаҳо
- Танҳо калимаҳои омӯхта
- То 25 савол, калимаҳои хато бештар такрор мешаванд
- Агар камтар аз 25 калима омӯхта бошад: **Барои санҷиш аввал ҳадди ақал 25 калима омӯзед.**
- Намудҳо: гӯш → навиштан, тоҷикӣ → англисӣ, англисӣ → интихоби тоҷикӣ, гӯш → интихоб

### Мушкилоти имрӯз
- Тақрибан 20–30 савол аз алифбо ва калимаҳои омӯхта
- Намоиш якто-якто, қисмҳои 5-тоӣ танҳо барои пешрафт
- Рӯйхати саволҳо як маротиба сохта мешавад ва захира мешавад

### Ёдраскуниҳо
- Вақт: 30 сония, 1 / 5 / 15 / 30 дақиқа, 1 соат
- Такрор: 1, 2, 3, 5, 10
- Саҳифаи **Ёдраскуниҳо**: давом / таваққуф / нест
- Ҳангоми оташ: TTS калимаро мехонад; агар TTS дар пасзамина кор накунад, огоҳӣ мемонад
- Огоҳӣ: **Вақти омӯзиш! 🔊** — `Apple — Себ`

### Пешрафт ва волидон
- Калимаҳои омӯхта / захира / душвор
- **Калимаҳое, ки боз такрор кардан лозим аст**
- **Таърихи санҷишҳо** бо ҷузъиёти хондашаванда
- **Тақвими омӯзиш** — рӯзҳои ҳафта бо ✓ / ·
- **Омори омӯзиш** — имрӯз, ҳафта, дақиқӣ, пайдарпай
- **Қулфи волидон**: PIN 4–6 рақам (хеш, на худи PIN)
- Пок кардани пешрафт: PIN → тасдиқ → PIN → «Ҳамаи пешрафт, натиҷаҳо ва захираҳо пок мешаванд.»

### Овоз
- Зан / Мард (агар дастгоҳ дошта бошад)
- Одатӣ 1.0x ё Суст 0.75x
- Агар овози мардона набошад: **Овози мардона дар дастгоҳи шумо дастрас нест.**
- Санҷиши овоз: «Hello! Let's learn English.»

### Дигар
- Калимаи имрӯз дар саҳифаи асосӣ
- Light / Dark / Auto, андозаи матн 85%–125%
- Саҳифаҳои Таҳиягар ва Дар бораи барнома
- Кор бе интернет
- Ҳангоми санҷиш, тугмаи Back: «Санҷиш идома дорад. Оё мехоҳед бароед?»

## Чаро экрани сиёҳ ислоҳ шуд

APK-и қаблӣ сохта мешуд, вале дар телефон экрани сиёҳ мемонд. Сабабҳои асосӣ:

1. **Хатои MediaQuery дар `MaterialApp.builder`** — `MediaQuery.of(context)` аз виҷети болои `MaterialApp` гирифта мешуд.
2. **Оғози барнома баста мешуд** — пеш аз `runApp()` плагинҳо интизорӣ мешуданд.
3. **ErrorWidget дар release холӣ аст**.

Ҳоло:

- аввал UI кушода мешавад;
- хидматҳои ихтиёрӣ баъд аз кадри аввал бо `try/catch` оғоз меёбанд;
- агар TTS, огоҳӣ, ёдрас ё распознаи овоз кор накунад, барнома кушода мемонад;
- логотип PNG-и аслии муштарӣ аст.


## Меъморӣ

- `lib/main.dart` — оғози бехатар, бе `await` пеш аз `runApp`
- `lib/app.dart` — `MaterialApp`, мавзӯъ, андозаи матн
- `lib/models/` — `AlphabetLetter`, `Word`, `TestSession`, `DailyActivity`, `MistakeRecord`
- `lib/services/test_engine.dart` — сохтани саволҳо як маротиба
- `lib/services/progress_service.dart` — ҳолати омӯзиш (`learning_state_v2`, иловашаванда)
- `lib/services/pin_service.dart` — PIN-и волидон бо хеш
- `lib/services/reminder_service.dart` — ёдрасҳо бо `flutter_local_notifications`
- `lib/services/tts_service.dart` — TTS-и танбал
- `data/vocabulary.json` — 500 калима
- `assets/logo.png` — логотипи аслӣ
- `tool/configure_android.py` — танзими Android барои CI

Плагини `android_alarm_manager_plus` истифода намешавад. Распознаи овоз ҳамчун баста илова нашуд, то оғоз ва иҷозатҳо хатарнок нашаванд: дар санҷиш ҳамеша **гӯш → навиштан** кор мекунад.


## TTS

Овоз **пеш аз кадри аввал** оғоз намеёбад.

Тартиби интихоб:

1. Овозҳои locale-и англисӣ
2. Ҷинси дархостшуда, агар metadata ё ном онро нишон диҳад
3. Агар набошад — дигар овози англисӣ
4. Ҳеҷ гоҳ барнома намеафтад


## Ёдрасҳо ва огоҳӣ

Аз корти калима тугмаи **⏰ Ёдрас** (на тақвим)-ро пахш кунед.

Дар вақти муайян:

- огоҳии Android бо калима, маъно ва шумораи такрор меояд;
- TTS кӯшиш мекунад калимаро хонад;
- агар TTS дар пасзамина манъ бошад, огоҳӣ ҳамоно кор мекунад.

Маҳдудиятҳои Android: баъзе телефонҳо TTS-и пасзамина ё alarm-и дақиқро маҳдуд мекунанд. Барнома ҳеҷ гоҳ аз ин сабаб экрани сиёҳ намедиҳад.


## Санҷишҳо ва ҳолат

- Рӯйхати саволҳо ҳангоми оғоз як маротиба сохта ва захира мешавад
- Ҷавоби додашуда дигар иваз намешавад
- Агар барнома баста шавад: «Санҷишро идома медиҳед?»
- **Баррасӣ** танҳо барои дидан аст
- Пешрафти мавҷуда (калимаҳои омӯхта/захира) ҳангоми навсозӣ нигоҳ дошта мешавад
